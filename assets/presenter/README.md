# AI presenter

Invented people only (generated by presenter_faces.py). Never Nathan, never a real person or a look-alike.

- presenter_A.png, presenter_B.png, presenter_C.png: candidates. Pick one and keep it for every video.
- jobs/<job>/: resumable work folders of presenter_talk.py (voice, word timings, shot plan, screen recordings, face shots).
- test/: rendered test videos. Not posted.

Rules for every script and upload:
- The presenter speaks as the brand's presenter. No testimonials, no "I am a customer", no results that did not happen.
- Every Instagram or Facebook upload must carry Meta's AI label. meta.json next to each video has ai_label_required: true,
  and the n8n uploader (Publish - Reel and FB Video) sets is_ai_generated on the Reel when the video meta has ai_generated
  or ai_label_required. Facebook /videos has no documented AI label field, so the uploader skips Facebook for these videos.
- The screen recording must match what the presenter says (the current demo is an estate agent email inbox, not a clinic phone line).

Run: Actions > presenter-talk > mode render, presenter A/B/C, model ltx. Free ZeroGPU covers about 3 face shots a day
(each LTX-2 call is a 3 s clip); if it stops with PARTIAL, run it again the next day with the same job name.
